## 📖 Post-Deployment Steps

After successful deployment:

### 1. Verify Deployment (5 minutes)

```bash
# Get service URLs
BACKEND_URL=$(gcloud run services describe ap2-expense-backend \
  --region us-central1 --format="value(status.url)")
FRONTEND_URL=$(gcloud run services describe ap2-expense-frontend \
  --region us-central1 --format="value(status.url)")

# Test health endpoints
curl $BACKEND_URL/health
curl $BACKEND_URL/api/webhooks/gcp/health

# Access frontend
open $FRONTEND_URL  # Mac
start $FRONTEND_URL  # Windows
```

### 2. Configure Stripe Webhooks (10 minutes)

1. Go to [Stripe Dashboard → Webhooks](https://dashboard.stripe.com/webhooks)
2. Click "Add endpoint"
3. Endpoint URL: `https://your-backend-url/webhooks/stripe`
4. Select events:
   - `checkout.session.completed`
   - `customer.subscription.created`
   - `customer.subscription.updated`
   - `customer.subscription.deleted`
   - `invoice.payment_succeeded`
   - `invoice.payment_failed`
5. Copy the signing secret
6. Update secret in Secret Manager:
   ```bash
   echo "whsec_..." | gcloud secrets versions add stripe-webhook-secret --data-file=-
   ```

### 3. Configure GCP Marketplace (30 minutes)

Follow the guide: `backend/GCP_MARKETPLACE_TESTING.md`

Key steps:
1. Create service account
2. Configure procurement webhook URL
3. Set up usage reporting (Cloud Scheduler)
4. Create test entitlement
5. Verify webhook processing

### 4. Set Up Custom Domain (Optional, 20 minutes)

```bash
# Backend (API)
gcloud run domain-mappings create \
  --service ap2-expense-backend \
  --domain api.yourdomain.com \
  --region us-central1

# Frontend
gcloud run domain-mappings create \
  --service ap2-expense-frontend \
  --domain yourdomain.com \
  --region us-central1

# Configure DNS records as instructed by GCP
# SSL certificates provision automatically (10-15 minutes)
```

### 5. Set Up Monitoring (15 minutes)

```bash
# Create monitoring dashboard
gcloud monitoring dashboards create --config-from-file=monitoring-dashboard.json

# Set up alerts for:
# - High error rate
# - Slow response time
# - High database connection count
# - Low disk space
```

## 🆘 Troubleshooting

### Issue: "gcloud command not found"
**Solution:** Install gcloud CLI from https://cloud.google.com/sdk/docs/install

### Issue: "Permission denied" errors
**Solution:** Ensure you're authenticated and have proper IAM permissions
```bash
gcloud auth login
gcloud config set project YOUR_PROJECT_ID
```

### Issue: Deployment script fails
**Solution:** Check logs and retry
```bash
# View build logs
gcloud builds list --limit=5

# View service logs
gcloud run services logs read ap2-expense-backend --region us-central1
```

### Issue: Health check fails
**Solution:** Check if secrets are configured
```bash
gcloud secrets list
gcloud run services describe ap2-expense-backend --region us-central1
```

### Issue: Database connection fails
**Solution:** Verify Cloud SQL instance and connection string
```bash
gcloud sql instances list
gcloud secrets versions access latest --secret=database-url
```

**For more troubleshooting:** See `QUICK_REFERENCE.md` section on troubleshooting
