 📋 HOW TO START THE APPLICATION
═══════════════════════════════════════════════════════════════

STEP 1: Start Backend Server
-----------------------------
Open Terminal/Command Prompt #1:

cd backend
.venv\Scripts\python.exe -m uvicorn src.api:app --host 0.0.0.0 --port 8000 --reload

Expected output:
  INFO:     Uvicorn running on http://0.0.0.0:8000
  INFO:     Application startup complete.


STEP 2: Start Frontend Server
------------------------------
Open Terminal/Command Prompt #2:

cd frontend
npm run dev

Expected output:
  VITE v5.x.x  ready in xxx ms
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/

═══════════════════════════════════════════════════════════════
 👤 ROLE CAPABILITIES
═══════════════════════════════════════════════════════════════

🟢 EMPLOYEE
-----------
Purpose: Submit and track personal expenses

Can:
  ✅ Submit expenses
  ✅ View/edit/delete own expenses (pending only)
  ✅ Withdraw pending expenses
  ✅ Upload receipts
  ✅ Add comments to own expenses
  ✅ View own reports

Cannot:
  ❌ Approve/reject expenses
  ❌ View other users' expenses
  ❌ Access admin features


🟡 MANAGER
----------
Purpose: Oversee department expenses and approvals

Can (All employee permissions +):
  ✅ Approve/reject department expenses (up to $5,000)
  ✅ View department expenses
  ✅ Bulk approve/reject
  ✅ View department reports
  ✅ Export reports

Cannot:
  ❌ Approve own expenses (self-approval prevention)
  ❌ Approve expenses over $5,000 (requires admin)
  ❌ Approve expenses from other departments (when departments set)
  ❌ Manage users or change roles
  ❌ Access system settings

Approval Limit: $5,000 per expense
Department Scope: Can only approve expenses from their department (when set)


🔵 ACCOUNTANT
-------------
Purpose: Financial oversight and reporting

Can (All employee permissions +):
  ✅ View all expenses (read-only)
  ✅ View all reports
  ✅ Export financial data
  ✅ View audit logs
  ✅ Access billing information

Cannot:
  ❌ Approve/reject expenses
  ❌ Manage users
  ❌ Access system settings


🔴 ADMIN
--------
Purpose: System administration

Can:
  ✅ ALL permissions (superuser)
  ✅ Approve expenses of any amount
  ✅ Approve expenses from any department
  ✅ Manage users (create, suspend, delete, change roles)
  ✅ Configure system settings
  ✅ Perform database maintenance
  ✅ Access all data

No restrictions

═══════════════════════════════════════════════════════════════
 📧 EMAIL NOTIFICATIONS
═══════════════════════════════════════════════════════════════

Email notifications are sent for the following events:

| Event              | Recipient(s)        | Method                       |
|--------------------|---------------------|------------------------------|
| Expense submitted  | Employee            | notify_expense_submitted()   |
| Expense submitted  | All managers/admins | notify_manager_new_expense() |
| Expense approved   | Employee            | notify_expense_approved()    |
| Expense rejected   | Employee            | notify_expense_rejected()    |
| Comment added      | Relevant parties    | notify_comment_added()       |

Configuration:
  - Emails are sent using SMTP (configured in .env)
  - Enable/disable: Set NOTIFICATIONS_ENABLED=true/false in .env
  - Test mode: Emails log to console if SMTP not configured

Email Format:
  - HTML + Plain text multipart messages
  - Includes expense details, amounts, approval status
  - AP2 transaction IDs for approved expenses


═══════════════════════════════════════════════════════════════
 🔄 EXPENSE WORKFLOW
═══════════════════════════════════════════════════════════════

1. SUBMISSION (Employee)
   └─> Status: PENDING
       └─> Email sent to employee (confirmation)
       └─> Email sent to all managers/admins (notification)

2. APPROVAL PROCESS
   ├─> Manager reviews (if amount ≤ $5,000 and same department)
   │   ├─> APPROVE → Status: APPROVED
   │   │   └─> AP2 transaction created
   │   │   └─> Email sent to employee
   │   │   └─> Audit trail created
   │   │
   │   └─> REJECT → Status: REJECTED
   │       └─> Rejection reason required
   │       └─> Email sent to employee
   │
   └─> Admin reviews (if amount > $5,000 or different department)
       ├─> APPROVE → Status: APPROVED
       └─> REJECT → Status: REJECTED

3. EMPLOYEE ACTIONS
   ├─> Edit (if PENDING)
   ├─> Withdraw (if PENDING) → Status: WITHDRAWN
   └─> Add comments (any time)

4. ACCOUNTANT ACTIONS
   └─> View all expenses (read-only)
   └─> Export reports
   └─> View audit trails


═══════════════════════════════════════════════════════════════
 🛠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Backend won't start
Solution:
  1. Check if port 8000 is already in use:
     netstat -ano | findstr :8000  (Windows)
     lsof -i :8000  (Mac/Linux)

  2. Kill the process or use a different port:
     .venv\Scripts\python.exe -m uvicorn src.api:app --port 8001 --reload

Problem: Frontend won't start
Solution:
  1. Check if port 5173 is in use
  2. Delete node_modules and reinstall:
     cd frontend
     rmdir /s /q node_modules  (Windows)
     rm -rf node_modules  (Mac/Linux)
     npm install

Problem: "Permission denied" errors
Solution:
  Check user role and permissions:
  - Managers can only approve ≤ $5,000
  - Users cannot approve own expenses
  - Managers can only approve their department (when departments set)

Problem: Email notifications not working
Solution:
  1. Check SMTP settings in backend/.env:
     SMTP_SERVER=smtp.gmail.com
     SMTP_PORT=587
     SMTP_USERNAME=your-email@gmail.com
     SMTP_PASSWORD=your-app-password
     NOTIFICATIONS_ENABLED=true

  2. For Gmail, create an App Password:
     https://myaccount.google.com/apppasswords

Problem: Tests failing
Solution:
  cd backend
  .venv\Scripts\python.exe -m pytest tests/test_permissions.py -v
