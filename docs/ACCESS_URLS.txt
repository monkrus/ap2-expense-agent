If NONE of these work:

1. Kill both servers:
   - Press Ctrl+C in both terminal windows

2. Restart them:

   Backend:
   cd backend
   python -m uvicorn src.api:app --reload --port 8000 --host 0.0.0.0

   Frontend:
   cd frontend
   npm run dev -- --host 0.0.0.0
